# Aquarius v0.1.10

This is a pre-release stability + Easter-egg build based on v0.1.9.

## Important Wi-Fi fix
Aquarius no longer commits a newly entered Wi-Fi password to NVS until the connection succeeds. If authentication fails, the previous saved network is restored automatically. The Wi-Fi page also has a `FORGET` control that clears saved credentials without resetting the rest of Aquarius.

## Calendar secrets
- 03:33 — Ghost Hour
- Friday the 13th — recurring cursed-water / skeleton-fish windows
- 14 February — heart bubbles
- 1 April — rubber duck
- 29 February — Leap Fish
- 31 October — pumpkin + ghost visitors
- 25 December — festive lights
- 1 January shortly after midnight — New Year sparkles
- Sunrise/sunset — short dawn/dusk ray visitor windows

These events use Aquarius's local NTP-synchronised clock, so correct Wi-Fi/time configuration is required.
