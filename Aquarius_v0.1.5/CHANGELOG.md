# Changelog

## v0.1.5 — Settings
- Revised resident fish setting to support 1–10 simultaneous fish.
- Expanded bubble and plant density controls to 0–10.
- Added a permanent animated crab patrolling the seabed.
- Added long-press touchscreen settings interface.
- Added persistent ESP32 Preferences/NVS storage.
- Aquarium controls: fish count, bubbles, plants, animation, weather FX, rare-event frequency.
- System controls: brightness, night brightness, auto-dim, clock format and temperature-unit preferences.
- Added About page with firmware, Wi-Fi, sensor and location status.
- Normal tap remains fish feeding. Dashboard layout remains locked.
