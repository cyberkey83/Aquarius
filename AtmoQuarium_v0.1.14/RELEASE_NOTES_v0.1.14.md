# AtmoQuarium v0.1.14

Refinement and bug-fix build.

## Changes
- Removed the stone-head ornament from the boot screen.
- Reduced boot bubbles to a sparse four-bubble animation.
- Boot bubbles now use the same colour blend as aquarium bubbles.
- Removed opaque backgrounds behind indoor/outdoor sensor values.
- Reworked CYD backlight PWM setup and made the dim level much lower and obvious.
- Added dim-state reporting to serial output and the hidden diagnostics screen.
- Added a gentle calm-weather surface swell every 4–6 minutes.
- Calm swell is deferred or cancelled while the hourly fishing boat is visible.
- Added a CALM SURFACE WAVE scene to Demo Mode.
