Aquarius

Aquarius is an animated ASCII aquarium and environmental dashboard for the ESP32 Cheap Yellow Display (CYD).

Rather than presenting weather information in a traditional dashboard, Aquarius creates a living desktop companion. Fish, bubbles and seaweed animate continuously while live environmental data is overlaid using a minimalist terminal-inspired interface.

Current features include:

- Animated ASCII aquarium
- Indoor temperature, humidity and pressure (BME280)
- Outdoor weather via Open-Meteo
- Wi-Fi connectivity
- NTP clock with automatic timezone support
- Touchscreen support
- Designed for ESP32-2432S028R (CYD)

Future plans include:

- Weather-responsive aquarium effects
- Sunrise and sunset lighting
- Pressure trend indicators
- OTA firmware updates
- Configuration menu
- Home Assistant integration
