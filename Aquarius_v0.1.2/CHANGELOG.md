# Changelog

## v0.1.2 — Behaviour Pass

- Locked the v0.1.1 dashboard layout with no visual restructuring.
- Added four distinct common-fish personalities: Calm, Explorer, Social and Darting.
- Added independent vertical cruising targets and occasional voluntary turns.
- Added eased horizontal acceleration so fish no longer snap instantly to a new speed.
- Added a three-stage feeding behaviour: approach, frenzy and recovery.
- Fish now converge on the tapped feeding point, circle more actively during the frenzy, then settle back into normal cruising.
- Food pellets now arrive in a finite falling wave instead of continuously looping.
- Added animated tail flick and a small dorsal fin to common/rare fish sprites.
- Improved squid behaviour with pulsed propulsion and short speed bursts.
- Improved octopus behaviour with seabed crawling and random pauses.
- Improved jellyfish vertical bobbing and differentiated visitor speeds.
- Retained weather-driven activity/depth, touch feeding, squid, octopus, rare visitors and submarine events from v0.1.1.
