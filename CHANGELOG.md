# Changelog

## v0.0.3
- Added `IndoorSensor` abstraction.
- Added generic `IndoorReading`.
- Added BME280/BMP280 auto-detection.
- Added optional DHT22 support.
- Added support model for BME280, BMP280, DHT22, and BMP280+DHT22.
- Added measurement-source reporting.
- DHT22 remains disabled by default pending a clean CYD GPIO connection strategy.
